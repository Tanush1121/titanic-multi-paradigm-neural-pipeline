# Multi-Paradigm Machine Learning Pipeline: Titanic Survival Matrix

## Project Overview
This repository contains a high-reliability, 17-module machine learning evaluation architecture designed to analyze human-system survivability patterns within the historical 1912 maritime demographics space. 

Taking inspiration from the safety-critical software engineering frameworks utilized by global aerospace entities like **ISRO** and **NASA**, this system moves past simple metric maximization to emphasize model explainability, operational calibration, and algorithmic resilience.

---

## Technical Architecture & Core Modules
The framework evaluates passenger risk states sequentially across 17 automated processing phases:

1. **Ingestion & Feature Synthesis:** Advanced text mining for social frameworks and group-based demographic median imputation.
2. **White-Box Rules Engine:** Initial deterministic baseline mapping using an interpretable Decision Tree.
3. **Continuous Probability Mapping:** Mapping linear log-odds onto a probability bound using the mathematical Sigmoid distribution.
4. **Unsupervised Spatial Partitioning:** Injecting non-linear clustering feature vectors via K-Means.
5. **Deep Learning Network:** Deployment of a Multi-Layer Perceptron (MLP) with Dense blocks and Dropout regularization.
6. **Generative Feature Discovery:** Mapping deep latent interactions through a Bernoulli Restricted Boltzmann Machine (RBM).
7. **Performance Grid Auditing:** Multi-paradigm comparative analysis utilizing Receiver Operating Characteristic (ROC) arrays.
8. **Explainable AI (XAI):** Interrogating black-box layers via game-theoretic SHAP marginal log-odds value tracking.
9. **Operational Calibration:** Frontier tracking to dynamically optimize the classification threshold at the harmonic $F_1$ peak.
10. **Ethical Bias Assessment:** Measuring system accountability against demographic drift using the standard Disparate Impact Ratio (DIR).
11. **System Stress-Testing:** Evaluation of structural degradation bounds under artificial White Gaussian Noise perturbation.
12. **Consensus Voting Layer:** Merging heterogeneous architectures into a Soft-Voting Meta-Ensemble.
13. **Topology Grid Sweeps:** compiliing hyperparameter spaces into interactive 3D surface mesh landscapes.
14. **Collinearity Auditing:** Mapping multivariable dependencies using global Pearson Correlation coefficients.
15. **Residual Variance Mapping:** Tracking system distortion via error kernel density estimations ($y - \hat{y}$).
16. **Stability Verification:** Determining model operational variance across data folds via Stratified 5-Fold Cross-Validation.
17. **Technical File Serialization:** Exporting compiled system summaries and neural network weight topologies (`.h5`).
